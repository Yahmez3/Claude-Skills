# Launch tweet thread — skeleton

10 tweets. First one matters 10x more than the rest.

---

**1/ (the hook)**
Short. No "introducing". State what the app does + who it's for + one surprising fact.

> Budget Buddy is live: envelope budgeting with offline sync. One purchase. No subscription. Live on Product Hunt today: {{ url }}
> [attach: 5-sec GIF of the core interaction]

**2/ (the why)**
Why this exists. The thing you noticed that nobody else built.

> Everyone I know uses a budgeting app until the subscription renewal — then churns. Envelope budgeting doesn't need a cloud bill.

**3/ (the proof)**
Numbers, beta feedback, or a specific capability demo.

> 200 beta users over 3 months. D7 retention: 68%. The top request was "never tell me to upgrade" — so we didn't.

**4/ (the differentiator)**
What's unique. Show it.

> Every transaction is editable offline. Sync is CRDT-based — no "last write wins" data loss.
> [attach: screenshot or GIF]

**5-7/ (feature highlights)**
One feature per tweet. One image per tweet.

**8/ (the ask)**
Be specific. "Upvote on PH" is better than "check us out".

> If this resonates, an upvote on Product Hunt today is the single most helpful thing: {{ ph_url }}

**9/ (credits)**
Thank the humans.

> Built by {{ team }}. Beta testers: {{ handles }}. Design: {{ handle }}.

**10/ (CTA)**
End with the download links. Pin this tweet.

> iOS: {{ url }}  ·  Android: {{ url }}  ·  Web: {{ url }}

---

## LinkedIn version

Same structure, longer paragraphs, less rapid-fire. Lead with a one-sentence story. Link lives at the end of the post (LinkedIn de-ranks posts with early links).

## Reddit version

Only post where you're a regular. Respect each sub's self-promo rules (often 10:1 comments-to-posts). Lead with the problem, not the product.
