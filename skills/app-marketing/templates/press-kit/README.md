# Press kit

Host at `{{ domain }}/press`. Link it from the site footer, from pitches, and from PH.

## Required assets

- `logo.svg` + `logo.png` (light + dark variants)
- `icon-1024.png`
- `screenshots/` — 10 high-res, properly named (`01-home.png` …)
- `hero.jpg` — a single cover image for social share
- `demo.mp4` — 30-60s silent walkthrough (captioned)
- `demo.gif` — 5s loop for Twitter/LinkedIn
- `founder-headshot.jpg` — min 1200×1200, neutral background

## Required text

- `fact-sheet.md` (below)
- `boilerplate.md` — 60-word and 150-word versions of "what the company is"
- `team.md` — names, roles, headshots, one-sentence bios
- `press-release.md` — only if you're doing a formal launch
- `coverage.md` — running log of press mentions (start empty, update as you go)

## Fact sheet template

```
App name:       {{ app_name }}
Tagline:        {{ ≤8 words }}
One-liner:      {{ ≤20 words }}
Category:       {{ category }}
Platforms:      iOS / Android / Web
Price:          {{ free / $X one-time / $X/mo }}
Launch date:    {{ YYYY-MM-DD }}
Founders:       {{ names, roles }}
HQ:             {{ city }}
Funding:        {{ bootstrapped / $X seed from ... }}
Website:        https://{{ domain }}
App Store:      {{ url }}
Google Play:    {{ url }}
Press contact:  press@{{ domain }}
Social:         @{{ handle }}
```

## Pitch-email checklist

- [ ] Press kit URL in every pitch
- [ ] Offer an exclusive angle or embargo where appropriate
- [ ] CC a second team member only if it adds value
- [ ] Follow up once (7 days later), then stop
- [ ] Track responses in a simple sheet; never burn a contact
